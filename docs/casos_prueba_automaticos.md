```bash
# Frontend (desde raíz)
pnpm run test

# Backend
cd Backend && pnpm run test

# Ambos
pnpm run test && cd Backend && pnpm run test
```

### Decisiones Técnicas

1. **Vitest sobre Jest**: El proyecto usa ESM (`"type": "module"`), Vitest es nativo ESM
2. **Mocks exclusivos**: Nunca se toca la base de datos real; todos los repositorios y servicios externos se mockean
3. **user-event v13.5.0**: No tiene `.setup()`, se usa API directa (`userEvent.click()`, `userEvent.type()`)
4. **framer-motion**: Se mockea con `makeTag()` que extrae `whileHover/whileTap` y renderiza el tag HTML plano
5. **lucide-react**: Se usa lista explícita de iconos (el Proxy intermitente causaba errores)
6. **setup.js**: Backend setea env vars antes de imports; frontend provee localStorage y fetch mocks
