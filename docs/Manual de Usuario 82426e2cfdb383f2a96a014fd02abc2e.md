# TABLA DE CONTENIDO

# 1. OBJETIVO

El presente Manual de Usuario tiene como objetivo proporcionar una guía clara y práctica para el uso de la plataforma web Psychoway. El documento está dirigido a los diferentes usuarios que interactúan con el sistema y explica las principales funcionalidades disponibles de acuerdo con el rol asignado.

A través de este manual, el usuario podrá conocer cómo acceder a la plataforma, navegar por sus diferentes módulos, realizar las operaciones disponibles y solucionar algunos de los inconvenientes más frecuentes que pueden presentarse durante el uso del sistema.

![image.png](Manual%20de%20Usuario/image%201.png)

# 2. ALCANCE

Este manual comprende las funcionalidades principales de la plataforma Psychoway y los procedimientos necesarios para que los usuarios puedan utilizar correctamente el sistema.

La documentación contempla las funciones disponibles para los roles **Aprendiz, Psicólogo y Administrador**, así como los módulos relacionados con usuarios, diario de emociones, agenda de encuentros, Psychobot y ajustes de la cuenta.

## 2.1. Alcance funcional

Psychoway es una plataforma web orientada a facilitar el acceso de los aprendices del SENA a herramientas de apoyo psicológico mediante diferentes funcionalidades digitales.

El sistema permite realizar procesos relacionados con:

- Gestión de usuarios.
- Registro e inicio de sesión.
- Recuperación de contraseña.
- Registro y seguimiento de emociones.
- Gestión de objetivos personales.
- Agendamiento y gestión de encuentros.
- Acceso a videollamadas.
- Interacción con Psychobot.
- Gestión del perfil.
- Configuración de privacidad.
- Administración de usuarios y roles.

Los principales módulos funcionales de Psychoway son:

| Módulo | Descripción |
| --- | --- |
| **Usuarios** | Permite realizar procesos relacionados con registro, autenticación, recuperación de contraseña y administración de usuarios. |
| **Diario** | Permite registrar y realizar seguimiento de las emociones y gestionar objetivos. |
| **Agenda** | Permite gestionar encuentros entre aprendices y psicólogos. |
| **Chatbot** | Permite interactuar con Psychobot mediante conversaciones orientadas al apoyo psicológico. |
| **Ajustes** | Permite gestionar información del perfil y configuraciones de privacidad. |

![image.png](Manual%20de%20Usuario/image%202.png)

## 2.2. Alcance organizacional

Psychoway cuenta con tres roles principales, cada uno con diferentes permisos y funcionalidades dentro del sistema.

### Aprendiz

El Aprendiz es el usuario principal de la plataforma. Puede utilizar herramientas destinadas al seguimiento de sus emociones, gestión de objetivos, agendamiento de encuentros e interacción con Psychobot.

Entre sus principales funcionalidades se encuentran:

- Registrar emociones.
- Consultar el historial de emociones.
- Consultar gráficas de seguimiento.
- Crear, modificar y eliminar objetivos.
- Marcar objetivos como cumplidos.
- Consultar objetivos pendientes y cumplidos.
- Consultar espacios disponibles.
- Gestionar encuentros.
- Ingresar a videollamadas.
- Utilizar Psychobot.
- Modificar información de su perfil.
- Modificar su contraseña.
- Gestionar opciones de privacidad.
- Eliminar su cuenta.

### Psicólogo

El Psicólogo es el usuario encargado de realizar actividades relacionadas con el seguimiento de los aprendices y la gestión de encuentros.

Entre sus principales funcionalidades se encuentran:

- Consultar aprendices.
- Consultar información relacionada con el seguimiento emocional.
- Visualizar gráficas de emociones.
- Consultar la última emoción registrada.
- Consultar el historial de encuentros.
- Gestionar encuentros.
- Ingresar a videollamadas.

![image.png](Manual%20de%20Usuario/image%203.png)

### Administrador

El Administrador es el usuario encargado de las funciones administrativas relacionadas con las cuentas de usuario y sus roles.

Entre sus principales funcionalidades se encuentran:

- Crear usuarios.
- Modificar usuarios.
- Eliminar usuarios.
- Modificar roles de usuario.
- Gestionar la información correspondiente a las cuentas.

# 4. INTRODUCCIÓN

Psychoway es una plataforma web integral diseñada para acercar a los aprendices del SENA a herramientas de apoyo psicológico mediante una interfaz digital accesible y amigable.

La plataforma permite que los aprendices realicen un seguimiento de sus emociones mediante el **Diario de Emociones**, gestionen objetivos personales, programen encuentros con psicólogos y utilicen **Psychobot**, un asistente basado en inteligencia artificial disponible para interactuar con el usuario.

Por otra parte, los psicólogos cuentan con herramientas para realizar seguimiento de la información emocional de los aprendices y gestionar encuentros, mientras que los administradores disponen de funcionalidades orientadas a la administración de usuarios y roles.

Psychoway se encuentra organizada mediante diferentes módulos que permiten separar las funcionalidades según las necesidades y permisos de cada usuario.

# 5. OBJETIVO DEL SISTEMA DE INFORMACIÓN DESARROLLADO

Psychoway tiene como objetivo facilitar el acceso de los aprendices del SENA a herramientas digitales de apoyo psicológico, proporcionando funcionalidades que permitan realizar seguimiento de las emociones, establecer objetivos, gestionar encuentros con psicólogos y acceder a un asistente de inteligencia artificial.

El sistema busca centralizar estas funcionalidades dentro de una plataforma web, permitiendo que cada usuario acceda únicamente a las opciones correspondientes a su rol.

De esta manera, Psychoway proporciona herramientas para:

- Facilitar el registro y seguimiento de emociones.
- Permitir la gestión de objetivos personales.
- Facilitar la programación de encuentros con psicólogos.
- Permitir la realización de encuentros mediante videollamadas.
- Proporcionar un asistente de inteligencia artificial mediante Psychobot.
- Facilitar el seguimiento de los aprendices por parte de los psicólogos.
- Administrar usuarios y roles mediante el perfil de administrador.

Para utilizar Psychoway, el usuario debe disponer de un equipo con acceso a Internet y un navegador web compatible.

### Requisitos generales

- Computador o dispositivo compatible con navegación web.
- Conexión estable a Internet.
- Navegador web actualizado.
- Credenciales de acceso válidas.

### Navegación

Se recomienda utilizar una versión actualizada de navegadores modernos como:

- Google Chrome.
- Microsoft Edge.
- Mozilla Firefox.

El usuario debe ingresar a la dirección web proporcionada para acceder a la plataforma.

![image.png](Manual%20de%20Usuario/image%206.png)

## 6.2. Configuración del sistema en el computador del usuario

Psychoway funciona como una aplicación web, por lo que el usuario final no necesita instalar el frontend, backend, base de datos ni herramientas de desarrollo para utilizar la plataforma.

El usuario únicamente necesita:

1. Disponer de conexión a Internet.
2. Abrir un navegador web compatible.
3. Ingresar a la dirección de Psychoway.
4. Contar con las credenciales correspondientes a su cuenta.

# 6.3.4. MÓDULO CHATBOT — PSYCHOBOT

Psychobot es el asistente de inteligencia artificial integrado en Psychoway. Su función es permitir que el usuario mantenga una conversación y reciba respuestas orientadas al apoyo psicológico.

![image.png](Manual%20de%20Usuario/image%2022.png)

### Gestión de mensajes

El usuario puede escribir mensajes en el campo de conversación y enviarlos a Psychobot.

El sistema procesa el mensaje mediante el servicio de inteligencia artificial y presenta la respuesta dentro de la conversación.

La disponibilidad de esta funcionalidad depende de contar con una conexión a Internet y de la disponibilidad del servicio de inteligencia artificial.

![image.png](Manual%20de%20Usuario/image%2023.png)

### Técnicas de apoyo psicológico

Psychobot puede proporcionar diferentes tipos de respuestas de apoyo, entre ellas:

- Técnicas de respiración.
- Frases de aliento.
- Consejos.
- Orientaciones ante situaciones en las que el aprendiz manifiesta encontrarse mal.

![image.png](Manual%20de%20Usuario/image%2024.png)

> **Nota:** Psychobot funciona como una herramienta de apoyo dentro de la plataforma y no reemplaza la atención profesional de un psicólogo.

# 9. SOLUCIÓN DE PROBLEMAS

Esta sección presenta algunos inconvenientes que pueden presentarse durante la utilización de Psychoway y las acciones que puede realizar el usuario para solucionarlos.

## 9.1. Problemas generales

### No puedo iniciar sesión

**Posible causa:** las credenciales ingresadas son incorrectas.

**Solución:**

1. Verifique que el número de documento sea correcto.
2. Verifique que la contraseña haya sido ingresada correctamente.
3. Si no recuerda la contraseña, utilice la opción de recuperación.

**[IMAGEN — Pantalla de inicio de sesión]**

### La plataforma no carga

**Posible causa:** problemas de conexión a Internet o indisponibilidad temporal del sistema.

**Solución:**

1. Verifique su conexión a Internet.
2. Actualice la página.
3. Compruebe nuevamente el acceso.

**[IMAGEN — Página/error de conexión]**

## 9.2. Problemas del Aprendiz

### No puedo registrar una emoción

**Posible causa:** falta de información obligatoria o problema temporal de conexión.

**Solución:**

1. Verifique que los campos obligatorios estén completos.
2. Compruebe la conexión a Internet.
3. Intente nuevamente guardar el registro.

**[IMAGEN — Formulario de registro]**

### Psychobot no responde

**Posible causa:** problema de conexión a Internet o indisponibilidad temporal del servicio de inteligencia artificial.

**Solución:**

1. Verifique la conexión a Internet.
2. Espere unos segundos y vuelva a enviar el mensaje.
3. Si el problema persiste, comuníquese con el responsable correspondiente.

**[IMAGEN — Chatbot]**

### No puedo agendar un encuentro

**Posible causa:** no existen espacios disponibles para la fecha seleccionada.

**Solución:**

1. Consulte otras fechas.
2. Revise los horarios disponibles.
3. Seleccione un espacio que se encuentre disponible.

**[IMAGEN — Agenda sin disponibilidad]**

## 9.3. Problemas del Psicólogo

### No puedo consultar la información de un aprendiz

**Posible causa:** el aprendiz no se encuentra disponible dentro de los registros correspondientes o existe un problema temporal de conexión.

**Solución:**

1. Verifique la lista de aprendices.
2. Compruebe la conexión.
3. Actualice la información.

**[IMAGEN — Lista de aprendices]**

### No puedo gestionar un encuentro

**Posible causa:** el horario seleccionado no se encuentra disponible.

**Solución:**

1. Consulte los espacios disponibles.
2. Seleccione otra fecha u hora.
3. Confirme nuevamente la información.

**[IMAGEN — Gestión de encuentros]**

## 9.4. Problemas del Administrador

### No puedo crear un usuario

**Posible causa:** falta información obligatoria o existen datos que ya se encuentran registrados.

**Solución:**

1. Verifique que todos los campos obligatorios estén completos.
2. Compruebe que la información no corresponda a un usuario existente.
3. Intente nuevamente realizar el registro.

**[IMAGEN — Formulario de usuario]**

### No puedo modificar el rol de un usuario

**Posible causa:** no se seleccionó correctamente el nuevo rol o no se guardaron los cambios.

**Solución:**

1. Seleccione nuevamente el usuario.
2. Seleccione el nuevo rol.
3. Guarde los cambios.
4. Verifique que la modificación haya sido aplicada.

**[IMAGEN — Modificación de rol]**
